# آزمون زندهٔ نشست مشترک و رابط آواتار پس از restart — ۲۰۲۶-۱۰-۲۲

## محیط و تأیید اپراتور

اپراتور اعلام کرد سرور را دوباره بالا آورده و ادامهٔ آزمون نشست و آواتار را خواست. محیط http://localhost:3000، نشست واقعی متخصص. سرور توسط دستیار متوقف نشد؛ هیچ SMS یا ورود جدید، cookie/token extraction، تغییر تنظیمات یا انتشار محتوا انجام نشد.

## نشست — بازگشت مشکل اصلی بازتولید نشد

در شروع auth/me و account/me برابر401 refresh_required بود؛ دسترسی واقعاً منقضی شده بود. کلیک دکمهٔ بازیابی به‌دلیل overlay آغاز صفحه timeout شد؛ این کلیک موفق اعلام نمی‌شود. یک POST معمول /api/auth/refresh:200 انجام شد و APIهای حساب به200 برگشتند.

سپس توالی آزمون ریشهٔ قبلی اجرا شد:

1. GET تازهٔ account/me200 و سند /account200، بدون صفحهٔ بازیابی.
2. یک POST دیگر /api/auth/refresh200 برای بازتولید کنترل‌شدهٔ انتقال A→B پس از primeکردن RSC.
3. GET account/me200 و سند تازهٔ /account200؛ recoverybutton در HTML نبود. prefix تشخیص در HTML نبود.
4. navigation کامل /account و بررسی DOM mounted: عنوان «حساب شخصی»، فرم موجود و یک inputfile موجود؛ overlay قبلی دیگر نبود.

نتیجه: در این اجرای پس از restart، مشکل مشخص fence_seal_mismatch/بازیابی پس از refresh تکرار نشد و فرم واقعی باز شد. این شاهد زنده محدود به topology تک‌پردازهٔ فعلی است، نه تضمین distributed/multiworker.

- در همین بازه صفحهٔ dev بارها به‌روزرسانی/بازسازی و خطاهای کنسول فراوان ثبت کرد؛ بعد از آپلود، انتخاب فایل/نتیجهٔ موقت از UI پاک شده بود. علت دقیق این بازسازی‌ها بررسی نشده و به HMR یا فایل مشخصی قطعی نسبت داده نمی‌شود. موفقیت API به معنی تأیید مرحلهٔ پیوستهٔ UI upload→attach نیست.

## آواتار حساب — انتساب و نمایش واقعی تأیید شد

به‌علت ازبین‌رفتن state موقت UI، انتساب از دکمهٔ attach آزموده نشد. همان attachment13 که آپلودش موفق بود، از مسیر ثابت و واقعی POST /api/account/me با avatar_id13 منتسب شد:200. GET مستقل id13 را تأیید کرد.

پس از navigation کامل /account، فرم حاضر بود و یک img واقعیِ همین فایل در DOM decode شد؛ ابعاد96×96. این شاهد نمایش mounted است، نه فقط SSR یا Image مستقل.

پیش از cleanup، currentavatar13 دوباره تأیید شد؛ سپس فقط avatar_idnull ارسال شد:200. GET مستقل بازگشت به null را تأیید کرد. GET profile/me200: آواتار حرفه‌ای10، publish، گالری1تصویر و revision7 ثابت بودند.
